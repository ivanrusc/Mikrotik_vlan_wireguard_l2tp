1. L2TP/IPsec multipunt

ElementValor

Limitació RouterOS: diversos clients L2TP/IPsec darrere de la mateixa NAT pública poden no funcionar amb el mode IPsec automàtic. En aquest cas, prefereix WireGuard.

VPN → MGMT, Proxmox, CT/VM i Internet: permès. VPN → WiFi / VLAN reservades: denegat.

RouterOS
/import file-name=02-fase2-l2tp-ipsec.rsc

2. Firewall L2TP/IPsec

  • UDP 500 — IKE
  • UDP 4500 — NAT-T
  • ESP — IPsec
  • UDP 1701 — només amb ipsec-policy=in,ipsec

RouterOS
/interface wireguard print detail\n/interface wireguard peers print detail\n/ping 10.255.255.2

4. Política WireGuard

El remot pot accedir a MGMT, Proxmox i CT/VM. Les xarxes locals MGMT/Proxmox/CTVM poden iniciar cap al remot si existeix una ruta. WiFi i les VLAN reservades continuen bloquejades.
