4. IPs permeses / denegades

Les llistes HOSTS-BLOCKED i HOSTS-ALLOWED permeten fer excepcions sense reescriure el firewall.

RouterOS
/ip firewall address-list add list=HOSTS-BLOCKED address=192.168.131.50 comment="Equip bloquejat"\n/ip firewall address-list add list=HOSTS-ALLOWED address=192.168.133.10 comment="Excepcio inter-VLAN"
Si bloqueges una IP que ja tenia connexions FastTrack/establertes, revisa i tanca les connexions existents perquè el canvi tingui efecte immediat.

5. IPv6

DHCPv6-PD corre sobre PPPoE-DIGI. El prefix delegat es divideix en /64 i se n'assigna un a MGMT, WiFi, Proxmox i CT/VM. VLAN134/135 no anuncien IPv6 mentre siguin reservades.

Sense NAT66: la protecció i segmentació IPv6 es fa amb firewall.

6. Validació real IPv6

Validat en RB750Gr3 amb RouterOS 7.20.7: el client DHCPv6-PD queda bound, DIGI entrega un prefix delegat /56 i RouterOS crea pool6-DIGI amb prefix-length=64.

DHCPv6-PD compatible i provat

RouterOS 7.20.7
/ipv6 dhcp-client
add interface=PPPoE-DIGI request=prefix pool-name=pool6-DIGI pool-prefix-length=64 add-default-route=yes use-peer-dns=yes disabled=no comment="DIGI DHCPv6-PD"
Nota de compatibilitat: no s'utilitza allow-reconfigure=yes. El dispositiu provat amb RouterOS 7.20.7 va rebutjar aquest paràmetre al CLI. No és necessari per rebre i utilitzar el prefix delegat.

Consumir un /64 del prefix delegat

RouterOS
/ipv6 address
add address=::1/64 from-pool=pool6-DIGI interface=bridge-LAN advertise=yes comment="IPv6 MGMT"

En aquesta configuració avançada s'utilitza el mateix mecanisme per MGMT, WiFi, Proxmox i CT/VM. Cada interfície consumeix un /64 diferent del prefix delegat.

Comprovacions

RouterOS
/ipv6 dhcp-client print detail
/ipv6 pool print detail
/ipv6 pool used print
/ipv6 address print detail
/ipv6 route print detail where dst-address="::/0"
/ping 2606:4700:4700::1111 count=5
/ping 2001:4860:4860::8888 count=5

Resultat validat: pings IPv6 a Cloudflare i Google amb 0% packet-loss.
